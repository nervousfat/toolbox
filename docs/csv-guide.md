# CSV 格式与转换边界

CSV → JSON 把第一条记录作为表头，其余记录作为对象。所有导入字段均为字符串：`001`、`true`、`12.00` 不会自动变成数字或布尔值。

## 输入格式

- 分隔符是英文逗号，不自动识别分号或制表符。
- 含逗号、换行或引号的字段应放在双引号内；字段内的双引号用两个双引号表示。
- CRLF、CR 和 LF 都会规范化为 LF，包括引号内的换行。因此原来的换行字节形式不会保留。
- 一个文件开头的 BOM 会被去掉；位于字段内部的 BOM 仍是字段内容。
- 表头不能为空或全为空白，也不能有完全相同的重复名称；其他前后空格会保留，因此 `name` 与 ` name` 是不同键。
- 每条数据记录的列数必须与表头相同。错误信息给出记录序号；引号内换行不会增加记录序号。
- 关闭引号后只能接逗号、换行或输入结束，不能再接空格或其他文本。

示例：

```csv
name,note
小明,"一行,含逗号"
小雨,"他说""你好"""
```

空输入得到空数组。仅有表头也得到空数组。最后一个换行符不会额外生成记录，但连续空白行会成为空字段记录，可能触发列数不一致。

## JSON 导出

输入必须是对象数组；null、数组元素或标量元素会被拒绝。输出表头由所有记录的自有字段组成，按首次遇到的顺序合并。缺失字段和 null 输出空文本；false、0 等值不会被当作缺失。嵌套数组和对象输出其 JSON 文本。

名为 constructor、toString、__proto__ 的列按普通自有字段处理，缺少这些列的记录不会读取对象继承值。

每个输出字段都使用双引号，记录之间使用 CRLF。空数组和没有任何字段的对象数组输出空字符串。

## 表格公式前缀

输出单元格（包括表头）如果以可选空白及 `=`、`+`、`-`、`@` 开头，会加一个单引号标记。原本已经有单引号的字段不再重复添加。负数字段也会带标记，例如 -12 输出的字段内容是 `'-12`。

这个处理会改变文本内容，CSV → JSON 不会自动删除标记。不同表格软件导入设置也会影响显示方式；先检查预览，再确认导入类型。不要把普通数值往返或带公式前缀的往返当成无损转换。

需要无损保存类型、null、嵌套结构或原字段集合时，保留 JSON 原件；CSV 更适合明确列结构的文本交换。
