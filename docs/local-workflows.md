# 本地使用与数据暂存

当前应用通过本机静态 HTTP 服务加载页面，转换函数在浏览器中运行。应用脚本没有 fetch、上传接口、远程分析请求或 localStorage/IndexedDB 持久化逻辑。输入和结果保存在当前页面的文本框中，刷新或关闭页面后不会由应用主动恢复。

浏览器自身的表单恢复、剪贴板历史、下载目录及扩展程序由浏览器和系统管理，不受这个 demo 控制。处理需要保留的内容时，先保存原件；不要将页面临时状态当成备份。

## 单次转换

1. 选择工具，确认说明中的输入类型。
2. 粘贴文本，点击转换或按 Ctrl+Enter（macOS 为 Command+Enter）。
3. 检查结果，必要时复制或下载。

转换失败时结果区会清空并显示错误，不会继续展示上一次成功结果。修改输入或切换工具也会清空结果，避免误把旧输出当成新输出。

切换工具保留输入。示例按钮会覆盖输入并立即运行所选工具；使用前先保存尚未导出的输入。

## 连续转换

完成一步后点击“结果移入输入”，再选择下一种工具。这个动作把结果替换到输入区并清空结果区，不保留之前的输入副本。

例如 JSON 格式化 → Base64 编码：先格式化并检查结构，再移入输入区、切换到 Base64 编码并转换。逆操作按相反顺序执行；CSV 类型转换、slug 等有损操作不适合作为可逆流程。

## 复制与下载

复制使用浏览器 Clipboard API。被权限或环境限制时，应用选中结果并提示手动复制；此时可使用系统复制快捷键。

下载通过当前结果创建文本 Blob，文件名由工具名称及 json、csv 或 txt 扩展名组成，不包含输入内容。浏览器仍可能询问保存位置。

结果为空字符串时，复制、下载和移入输入按钮禁用。空结果可能是有效输出，例如空对象数组转 CSV；先看转换状态，再判断是否错误。

清空按钮删除当前输入和输出。已经复制的系统剪贴板内容或已下载文件不会随之删除。
