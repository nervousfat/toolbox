# JSON 格式化、压缩与结构统计

工具接受标准 JSON 文本。对象、数组以及字符串、数字、布尔值、null 都可以作为根值。注释、尾逗号、单引号字符串、undefined 和 NaN 不是 JSON；转换失败时先修复原始输入。

## 格式化和压缩的区别

`prettyJson(text, spaces)` 的缩进参数必须是 0 到 8 的整数，默认 2。浏览器界面使用默认两空格；直接调用函数才可选择其他值。0 表示不插入排版空白。

`compactJson(text)` 返回以下字段：

| 字段 | 含义 |
| --- | --- |
| text | 重新序列化后的紧凑 JSON |
| before | 原输入的 UTF-8 字节数 |
| after | 输出的 UTF-8 字节数 |
| saved | `max(0, before - after)` |

压缩只移除排版空白，不会移除字符串里的空格、制表符或换行。字节数不是 JavaScript 字符串长度：中文、组合字符、emoji 的编码长度可能不同。极短数字的标准拼写可能变长，例如 `1e3` 输出 `1000`，此时 saved 是 0。

## 数据保真边界

转换使用 JavaScript 的 JSON.parse 和 JSON.stringify，因此保证的是其支持的数据值，不是原始字节逐一相同。

- 同名对象键只保留解析后的最后一个值，无法从结果恢复之前的重复键。
- 数字由 JavaScript Number 表示；超出安全整数范围的订单号、银行卡号等应由数据源以字符串提供。已经解析并舍入的数字不能靠再加引号恢复。
- 极大指数可能超出有限 Number 范围；负零、指数写法、转义字符写法也可能被标准化。
- 对象中类似非负整数的键可能按数字顺序输出；不要把对象键的原始书写顺序当成业务排序。
- 日期字符串仍是字符串，不会自动转换时区或校验日历日期。

处理前保留原文件，处理后用解析后的值检查所需字段，再替换原文件。

## 结构统计

`inspectJson(text)` 统计 objects、arrays、values 和 depth。根节点深度为 0；每经过一个对象属性值或数组元素深度加 1。null 是一个标量值，空对象和空数组计入容器数量，不增加 values。

例如 `{"a":[null,{}]}` 有 2 个对象、1 个数组、1 个标量，最大深度为 2。遍历使用显式待处理栈，避免递归函数调用；这不代表内存无限，超大输入仍应拆分。

相关回归测试位于 `tests/json-pretty.test.js`、`tests/json-compact.test.js` 和 `tests/json-inspect.test.js`。
